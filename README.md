# Karla's Daily Tech News

A live, single-page dashboard that tracks major American tech companies (public + private) with:

- Daily news headlines from reliable tech RSS feeds
- Overall sector theme summary
- Macro / economic updates that affect tech
- Automated **Timing Considerations** section (not financial advice)
- Search / filter for companies
- Support for private companies (OpenAI, Anthropic, SpaceX, Stripe, xAI, etc.)

---

## Download the Dashboard

### Option 1 – Direct Download from this repo
- [**Download index.html**](https://github.com/kulves/Karlas-Daily-Tech-News/raw/main/index.html) (right-click → Save Link As…)
- Or open the file page and click the **Download raw file** button:  
  https://github.com/kulves/Karlas-Daily-Tech-News/blob/main/index.html

### Option 2 – GitHub Pages (live version)
1. Go to **Settings → Pages**
2. Under "Source" choose **Deploy from a branch**
3. Select branch `main` and folder `/ (root)`
4. Save — your live dashboard will be at:  
   `https://kulves.github.io/Karlas-Daily-Tech-News/`

### Option 3 – Clone the repo
```bash
git clone https://github.com/kulves/Karlas-Daily-Tech-News.git
cd Karlas-Daily-Tech-News
open index.html   # or just double-click it
```

---

## How to use

1. Open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari).
2. The page loads news automatically. Use the **Refresh All** button or leave Auto on.
3. Use the search bar above the company cards to filter by name or ticker.

## Disclaimer

This is **not** financial advice. The timing section is an automated reading of headlines only.
